# Machine Learning Projects

## 1. [The Supreme Intelligence 5G Transmission Coverage](./1st%20project%20-%20The%20Supreme%20Intelligence%205G%20Transmission%20Coverage/)

Given **N** towers at fixed locations, which **K** should be removed so that the two closest remaining towers are as far apart as possible?

The task is to design and evaluate a metaheuristic for this selection problem in both two and three dimensions. Each candidate keeps exactly **N − K** towers and is scored by the shortest Euclidean distance between any two of them. Compare solution quality and runtime against a baseline such as greedy selection or random search.

## 2. [Humane University of Technology](./2nd%20project%20-%20Humane%20University%20of%20Technology/)

Which dietary patterns can be identified among university students, and how are those patterns associated with their living conditions and reasons for choosing particular foods?

The task is to group students using food consumption and survey data, then describe what distinguishes each group. Compare how the groups change when the analysis focuses on diet quality, lifestyle, or sustainable consumption. Justify the choice of features and the number of clusters, and assess how stable the resulting groups are.
